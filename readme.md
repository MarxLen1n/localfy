# 🎵 Descargador de Música de YouTube

Una aplicación de escritorio que descarga automáticamente la música de tus playlists de YouTube y te permite escucharla desde un reproductor integrado.

## ✨ Características

- 🔐 Inicia sesión con tu cuenta de Google para acceder a tus playlists de YouTube.
- ⬇️ Descarga automáticamente las canciones de tus playlists usando `yt-dlp`.
- 🎧 Reproductor integrado con controles básicos (play, pausa, siguiente, etc.).
- 💡 Descubre y descarga canciones recomendadas.
- ⭐ Marca tus canciones favoritas.
- 📂 Organiza tu música en playlists dentro de la aplicación.
- 🔍 Busca canciones por nombre, artista o playlist.
- 🖥️ Interfaz gráfica sencilla hecha con Tkinter.
